# 可填写模板

复制到自己的工作记录目录后填写，不在技能原件上混入项目结果。`待填写`/`未知` 是未完成状态，不是通过；没有数据的数值格不要填 0。

|模板|用途|
|---|---|
|[baseline-diagnosis.md](baseline-diagnosis.md)|计时边界、可解释时间账和优先候选|
|[migration-review.md](migration-review.md)|数值方案与历史成果继承矩阵|
|[experiment-report.md](experiment-report.md)|联合改动、正确性和 A/B/A 验收|
|[resource-experiment.md](resource-experiment.md)|结构证明、资源交换、拥塞及物理结果|
|[integration-checklist.md](integration-checklist.md)|Overlay、时钟、寄存器、缓冲和实时链路集成|
|[delivery-inventory.md](delivery-inventory.md)|运行/重建依赖、归档和恢复验证|
|[samples.csv](samples.csv)|A/B/A 工具接受的列名，只有表头，没有虚构样本|

通用项目输入使用 [project-contract.json](../project-contract.json)。独立硬件源码骨架见 [向量加法 HLS 模板](../../examples/vector_add_hls/README.md)，其当前验证范围与真实上板状态分开记录。
