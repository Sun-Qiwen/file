# 06：统一 Overlay 与 PS 调用集成

```text
使用本包 SKILL.md，将 <计算核> 接入 <目标 PYNQ 系统/外设链路>。
已有文件=<bit/HWH、RTL/IP、主机入口、约束>，本次范围=<仅本地/包含已授权板测>。

先核对是否需要改变 PL：仅主机适配且现有硬件接口足够时，不无故重建位流；
增加硬件功能时，建立包含全部模块的统一设计，避免一个驱动再次下载另一个完整 Overlay。
记录地址/IP/register_map、控制协议、设备地址位宽、缓冲布局、时钟/复位、CDC 和引脚。
完整系统资源预算包含互连、预览缓存等外设，不能只看计算核是否放得下。

主机侧明确单一 Overlay 所有者，区分 AXI DMA 和 m_axi 调用。
按真实方向同步缓存；完成条件包含必要排空，超时不能推出硬件停止或允许释放内存。
保留原输入预处理、数值规则和控制有效性，检查无输入、过期结果、连续调用与退出路径。
实时输入采用适合任务的队列策略，分别记录帧龄、推理与控制/显示延迟，不能用旧固定图时长替代。

用 assets/templates/integration-checklist.md 交付接口映射、所有权和验证记录。
仅本地任务不连接设备，所有未测试的摄像头/外设/外部时序明确保持待验。
```
