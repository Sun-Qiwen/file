# 专项提示词工作流

先让协作模型读取本包 `SKILL.md`，再复制对应文件里的提示词。将尖括号字段替换为当前工程信息；未知项写“未知”，优先从工程查找。提示词中的操作范围服从用户当前指示，不能从案例或文档自行推导上板、重置、清理或公开权限。

|当前问题|直接使用|输入重点|应得到的结果|
|---|---|---|---|
|不知道为什么慢|[01 基线诊断](01-baseline.md)|入口、计时样本、计数含义|可解释时间账与有证据的候选|
|计划量化或迁移旧优化|[02 精度与继承](02-precision-migration.md)|任务效果、数值规则、历史实现|精度决策、整数参考与继承矩阵|
|想合并优化减少构建次数|[03 联合优化](03-joint-optimization.md)|瓶颈、目标、资源与退路|局部筛选、联合实现和归因边界|
|资源多、装箱困难|[04 资源优化](04-resource.md)|层次/原语/控制集报告|资源归因、结构证明与可实现候选|
|布线冲突节点一直很多|[05 布线不收敛](05-routing.md)|迭代趋势、拥塞、约束|停止/继续依据、根因与恢复点|
|接入其他 IP 或新外设|[06 Overlay 集成](06-integration.md)|bit/HWH、地址、时钟和控制|统一 Overlay、主机适配与集成回归|
|准备最终验收|[07 回归与 A/B/A](07-acceptance.md)|身份、参考、样本、验证范围|分层正确性与性能结论|
|准备精简交付或归档|[08 交付与归档](08-delivery.md)|源码到运行包的依赖|最小交付清单、归档和恢复证据|

常见组合：新项目用 01→02→03/04→06→07→08；已有稳定数值方案跳过重新量化；持续拥塞时转 05，完成根因处理后回到原流程。一次任务可串联多个阶段，不要求每阶段另开对话或重复授权。

配套可填写材料见 [模板目录](../assets/templates/README.md)。不直接复制历史 case 的频率、bank 数、地址、资源预算或收益百分比。
