# 02：目标精度与历史优化迁移

```text
使用本包 SKILL.md，评估 <工程> 从 <当前方案> 到 <目标精度/架构> 的迁移。
原参考=<路径>，任务效果门槛=<指标>，当前允许范围=<只分析/本地实施/包含实板>。

先判断目标数值方案是否已经稳定；已有已接受的量化规则不重做校准或训练。
若尚未验证，先分开检查任务效果、目标数值参考和硬件实现可行性。
明确权重/激活、累加位宽、尺度、舍入、饱和和转换边界，允许有依据的混合精度。
模型修改或训练不在当前授权范围时，报告所需选择，不自行扩大任务。

逐项对比旧版与候选：burst、输入/权重复用、packed buffer、bank、流水重叠、
参数缓存、合法回退、控制协议与主机预处理，标记可继承/需适配/已失效及证据。
不要把 FP32 优化全盘推倒，也不要认为改成 INT8 后旧时序/布局证明自动有效。
优先迁移证据充分的缺失项，保持目标方案的参考与规则；局部验证后再合并实现。

用 assets/templates/migration-review.md 输出继承矩阵、迁移顺序和重新验证范围。
```
