# 已有手动金币策略板测证据

本目录对应当前无IoU、0.15、单帧、无超时的手动金币版本，不含目标方向或直线辅助实验。acceptance.json保留19项板端策略检查和6.205秒真实摄像头短局的验收摘要；result.json、inference.jsonl、rounds.jsonl和poststate.json为对应证据。

游戏期间欠载0、DDR读错误0，退出后显示和推理核空闲。当前正式时长仍是60秒；这组短测记录其实际场景，不用于推算完整60秒体验或真实识别准确率。项目作者另已确认此前多次上板测试完成，详见[构建与板测状态](../build_status.json)；该确认与本目录已归档的测量分开记录。
